# Página personal - Joel Solano

## Descripción

Este proyecto fue desarrollado para la materia Aplicaciones Web de UNIANDES, como parte de la tarea Introducción a HTML.

Consiste en una página web personal que muestra información sobre mí, mi formación académica y mis conocimientos. También incluye una calculadora desarrollada en PHP.

## Tecnologías utilizadas

- HTML5: estructura de la página.
- CSS3: diseño y estilos.
- PHP: operaciones de la calculadora.

## Calculadora

La página incluye una calculadora que permite realizar cuatro operaciones básicas: suma, resta, multiplicación y división.

## Ejecución del proyecto

1. Instalar XAMPP.
2. Copiar la carpeta `pagina-personal-joel` dentro de `htdocs`.
3. Iniciar Apache desde el panel de XAMPP.
4. Abrir `http://localhost/pagina-personal-joel/` en el navegador.
